# 試遊後の透過・境界案内・物理の修正

更新日: 2026-11-06 / 状態: ローカル版へ反映。

追加の試遊で見つかった箱・地面のちらつきと、コーンが穴に追随する問題は[おもちゃのテーマ試作](toy-stage-trial.md)と合わせて修正。以下はそれ以前の検証記録。

## 修正内容

### 半透明化を大きな遮蔽物に限定

- 現在の姿勢の衝突形状を水平に投影し、穴に入るサイズなら透過しない。球・円柱・凸形状も形に合わせて扱い、箱の対角線で一律に大きく見積もらない。
- 穴に入らない大物で、穴の中心と周囲8点のすべてを実際の描画が遮る場合だけ透過する。端の一点が隠れただけでは透過しない。
- カメラが物の外枠の内側にあるだけでは透過しない。机の脚の間など、実際には空いている場所での誤判定を防ぐ。
- 成長や姿勢の変化で入るサイズになった物は、すぐ通常の材質へ戻す。共有材質・物理・点数には影響させない。

### 境界の見た目と文字の読みやすさ

従来の巨大な門・看板を、現在の穴のサイズに合うコーンと低い柵へ変更した。近い境界だけに表示し、東西南北のすべてに対応する。近づくと画面内に16pxで「この先はレベル○で進めます」と表示する。画面幅が変わっても文字は縮小せず、操作を妨げない。

開放条件は従来どおりレベル4・7・10。高低差や門番の回収による開放は候補として残し、今回の修正では進行条件を変えない。

### サイズ・レベルによる物理固定を廃止

前回の改修で、対象レベルに達するまで物を固定剛体にしていたことが、部分的に接地面を失っても動かなかった原因。停泊船にも、穴が全体を覆うまで固定する処理があった。

近傍の物は、レベル・大きさ・停泊の役割に関係なく動的剛体で支える方式へ変更した。近い予告モデルは実物の描画と衝突形状へ切り替える。睡眠と遠方の休止は維持するが、穴の移動・成長で支持が変わる物を起こす。

歩行・走行などの制御も、足元と穴が重なると直立・操縦を解除する。傾いている物を毎フレーム直立へ戻さない。オーナーの確認により、細長い物などが傾いて穴へ落ちきった場合は、対象レベルに達していなくても回収・加点する。最終目標もレベル12の制限を外し、実際に飲み込めた時点でクリアする。加点による通常の成長は行うが、クリア時にレベル12へ強制変更しない。二重回収・クリア後の追加加点は防ぐ。

穴より大きいことは、必ず傾くことを意味しない。残った接地面が重心を支えている間は静止し、支えを失った方向へ物理演算で傾く。

## 種類の追加

[成長を実感できるオブジェクトの追加案](object-catalog-proposal.md)に、全8ステージのサイズ帯別候補と、港の12段階の具体例をまとめた。同じモデルの拡大に依存せず、主役の種類・形・役割を変える。今回の試作の種類・配置は維持する。

## 確認結果

- 245テスト（21ファイル）、型チェック、ビルド、Lint、対象ファイルの書式確認が成功。
- 小物、部分的な遮蔽、外枠内のカメラを透過対象から除外し、大きな遮蔽物の透過・復帰と、成長後の即時復帰を単体テストで確認。球・円柱・傾いた長い物の投影幅も確認。
- 穴に収まらない長い物が部分的な支持の喪失で傾くことを、0.1・1・100の縮尺で物理テスト。
- PC Chromiumの通常操作で、レベル2・穴半径0.14の状態から、接地の片側を失った木が約26.0度傾くことを確認。観測時の物の水平半径は約0.586で、穴より大きかった。
- 1280pxと390px幅の両方で四方向の境界を確認。案内は16pxで、画面内に収まり、入力で境界外へ進まない。
- 会社で、大きな机の透過・通過後の復帰・再開・タッチ操作を確認。
- 全8ステージをレベル1から12の最終目標まで通常操作でクリア。
- 最終配布物で、サーバー停止・通信遮断後の8ステージ起動、音声、更新、保存失敗からの再試行が成功。

## 回収・クリア条件の追加確認

上記の245テストと8ステージの確認後、オーナーが透過条件と「実際に飲み込めたらレベル不足でも回収・クリア」を確定した。最終目標のレベル12制限を削除し、249テスト（21ファイル）、型チェック、ビルド、Lint、対象ファイルの書式確認が成功した。

レベル1・7・11での最終目標の加点・クリア、二重加点の防止を確認。さらに、穴の直径より長い箱形の目標を使う物理テストで、レベル11の穴へ傾いて落ちきった後に加点・クリアし、レベルは通常のポイント計算で11のままとなることを確認した。この物理テストは細長い箱の検証用データを使い、既存のタンカーがレベル11で飲み込めると保証するものではない。

PC Chromiumでは港を通常入力でレベル1からタンカーの回収・クリアまで再確認し、おもちゃの街への自動移行も成功。ブラウザでの港のクリアはレベル12だった。実行時エラーは0件。この条件変更後の8ステージ通し直し、オフライン再確認、iPhone実機・WebKitは未実施。
