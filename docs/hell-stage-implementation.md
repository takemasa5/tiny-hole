## 空間と対象

12段階の成長と、穴の画面上の大きさ、平面の移動を維持する。小さい空間を大きい空間が囲み、成長すると以前の場所が小さく見える。床は河原・灰の道・火の広場・青い石畳・閻魔の庭へ変わる。水や火の色は床の模様で、追加のダメージや失敗条件は設けない。

| レベル | 場所           | 主な対象             | 次の開放               |
| ------ | -------------- | -------------------- | ---------------------- |
| 1〜2   | 賽の河原       | 小石、積み石         | レベル3で河原の出口    |
| 3〜4   | 小鬼の河原     | 小さな青い鬼         | レベル5で小鬼の門      |
| 5〜6   | 亡者の道       | 白い装束の亡者       | レベル7で亡者の門      |
| 7〜8   | 赤鬼の火の広場 | 大きくなった赤鬼     | レベル9で赤鬼の門      |
| 9〜11  | 青鬼の大広場   | さらに巨大な青鬼     | レベル12で閻魔の大門   |
| 12     | 閻魔の大庭     | 走って逃げる閻魔大王 | 実際に飲み込むとクリア |

- 境界は地面に固定した石の壁と赤い扉。開放条件は穴の接近時に16pxの画面案内で表示する。小鬼以降は、案内に捕獲で成長することも含める。
- 出口の外に鳥居を置き、成長前に見上げた同じ物を後から飲み込める比較対象にする。
- 閻魔は王冠・笏・紫の衣を持つ立ち姿へ変更。椅子や机と一緒に移動するモデルは使わない。寸法は180・450・145で、青鬼からさらに大きな相手になる。
- 初期配置は379個。小石48個、移動する通常対象144体、閻魔1体、環境物180個、出口の鳥居5個、御殿1個。13種類の形状を用意する。
- 環境物は積み石、灯籠、鳥居、地蔵、内部が空いた釜、針の岩山、御殿。終盤にも広範囲に配置する。走る対象の巡回路と壁を避けて配置する。
- 個数・寸法・速度・開放レベルは試作の仮値。

## 捕獲による成長

- 小石は各レベル24個。レベル1・2は小石を集めて成長する。
- 小鬼以降は各レベル16体を配置し、1体を同レベルの通常ポイントの3倍にする。開始点から同レベルの相手を約4体捕まえると次へ成長する。
- 静止物と囲いから得られる成長ポイントの合計は60（レベル3到達分）を上限とする。その後は静止物を飲み込めても成長ポイントは増えず、動く対象の捕獲が必要になる。静止物を大量に回収しても、この条件を突破できないことをテストする。
- 物理的に飲み込めた大きな対象は、目安レベル未満でも回収・加点する。閻魔も実際に落ちきった時点でクリアする。
- 現在レベルの未落下の対象が不足した場合は、空いた初期配置地点へ小石または同種の移動対象を補充する。穴のすぐ近くと他の物に重なる位置には補充しない。補充には既存の2秒周期を使い、無制限に数を増やさない。

## 動きと追跡

飲み込める水平外形になる前は巡回する。穴に入る大きさになって近づくと逃げる。通常時も既存の地獄より速め、巡回地点での停止は短くする。

| 対象 | 逃げ方                           | 穴の最高速に対する逃走速度 |
| ---- | -------------------------------- | -------------------------- |
| 小鬼 | 小刻みな切り返しと短いダッシュ   | 0.945倍と0.585倍           |
| 亡者 | 群れのようにゆらぎながら移動     | 0.85倍                     |
| 赤鬼 | 直線を主体にダッシュし、息を継ぐ | 0.972倍と0.54倍            |
| 青鬼 | 大きく弧を描いて回る             | 0.90倍と0.648倍            |
| 閻魔 | 長めのダッシュと方向の揺さぶり   | 1.10倍と0.62倍             |

穴の最高速は半径×7。試遊後の調整として、小鬼・赤鬼・青鬼の巡回・逃走速度を従来比10％下げた。鬼はダッシュ中も穴より少し遅く、追い続ければ距離を詰められる。小鬼・赤鬼・青鬼の逃走中の旋回を最大90度/秒に制限し、穴の位置が反転しても即座にUターンしない。最小回転半径はその時の速度÷（π/2）で、ダッシュ中は穴半径の約4.0〜4.3倍。壁際では曲がりきるまで停止し、壁を避けるための瞬間的な方向転換を行わない。穴と足元の水平外形が重なり始めると、残る足場に応じて自力移動を減速する。水平外形全体が穴の内側に入った鬼は地面を蹴れないため、自力移動を停止する。回収や落下を強制せず、支持喪失・傾き・落下は実際の物理演算を維持する。ダッシュ・回り込みの特徴は維持し、亡者と閻魔の速度・旋回は変更しない。逃走を開始する距離と解除する距離を分け、警戒の切り替わりを繰り返さないようにする。次の空間へ逃げ込んだり、巡回路を出た瞬間に初期位置へ引き戻されたりしないよう、各空間の外周と内側の壁を考慮して進行方向を選ぶ。

歩行中は直立を保ち、外形に穴が触れただけで転倒しない。実際に足元が沈んだら行動制御を解除し、傾き・落下は物理演算に従う。倒れた対象を再び自動で立たせる処理は加えない。

## 描画・当たり判定・負荷

- 床の模様はテクスチャへ描き、床を物体より先に描く既存の修正を引き継ぐ。重なった床板で装飾しない。既存の遮蔽面だけの透過と描画補間も共用する。
- 当たり判定はモデルの実際の部品から作り、鳥居・御殿の通り抜ける空間と、釜の内部を大きな箱で塞がない。顔の平面の絵柄は支持面にしない。
- 未開放の場所は遠方の目印を表示しつつ、そこでの物理演算を開始しない。環境物の物理演算は穴の近傍を中心に有効化する。
- 成長に対して微小になった地獄の物は、落下中・透過中・他の物との接触中を保護したうえで退役させる。見えない微小物だけが物理演算に大量に残らないようにする。

- 412件・28ファイルの自動テスト、ビルド・Lintが成功。1,000シードの配置・巡回路、静止物による成長の制限、全種類の実落下と衝突範囲、空いている通路・釜内部、5つの出口、速度と落下後の行動停止を確認した。
