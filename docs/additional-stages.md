- 8段階成長、ポイント閾値0・8・32・120・320・720・1500・2700、物理落下・傾き、画面中央で一定の表示径の穴を引き継ぐ。新しい制限時間・ダメージ・失敗条件は設けない。
- 清掃車1体・ランダム位置の通常工場2か所（会社は別に小型工場2か所）・ステージ固有のランダム供給・在庫不足時の補充を引き継ぐ。通常工場はレベル8、小型工場はレベル6で回収できる。
- 通常の物は種類ごとに地区へ分けず、地面パターンに沿うランダム配置。会社の開始時の小物だけは、見つけられる位置を確保する。
- モデル・地面はThree.jsの形状とCanvasで描画し、追加ライブラリ・外部画像・新規音声ファイルは使わない。

## 港

浮き → 樽 → 木箱・長い木材 → 小舟 → コンテナ → 巨大クレーン。

コンクリートの埠頭と黄色い搬送レーンに沿って荷物を置く。木箱の一部は3段に積む。樽と浮きは円柱、その他の荷物とクレーンは箱型の衝突形状で近似する。クレーンは脚・桁・運転席・吊り下げたフックを持つが、脚の間を通すための分割衝突形状や吊り荷の関節は今回の範囲に含めない。水上移動や浮力は追加しない。

## おもちゃの街

積み木・ボール → 汽車 → おもちゃの車・積み木の塔 → おもちゃの家 → 巨大ロボット。

色のついたマットと通路に沿って物を置く。積み木は8か所を20段積みにし、1個ずつ独立した剛体として崩す。ボールは球の衝突形状で転がる。汽車・車・家・ロボットは箱型で近似する。ロボットは座標の置き換えで消さず、全体を物理的に落として回収する。

## 会社

消しゴム・鉛筆 → ホチキス → 書類の束と山 → 事務椅子・書類棚 → 机・コピー機 → 社長の席。

- 会社だけ、半径0.08・0.12・0.20・0.28・0.42・0.62・0.9・1.6の8段階。通常の開始半径0.9の約1/11。画面上の穴の大きさは共通で、カメラを近づけて小物が大きく見えるようにする。
- 3段階目で書類の束の水平対角が穴に収まるようにする。初回の確認では半径0.18が束の対角半径約0.186を下回って文房具集めが長引いたため、0.20へ調整した。
- 寸法の例は、消しゴム0.04×0.02×0.025、鉛筆0.18×0.015×0.015、机1.4×0.75×0.7。文房具と人・家具の大きさの差を保つ。
- 狭いカメラでも最初の物が見つかるよう、開始地点の近くに消しゴム8個と鉛筆2本を確保する。その後の物はカーペットの通路沿いへランダム配置する。社員は通路内から歩き始める。
- 書類の束を10段にした山を8か所に置く。束ごとに独立した剛体とし、下から崩して回収できる。
- 社長は椅子・専用デスクと一体の最終目標。通常の社員のようには歩かず、専用デスク全体が入る最終サイズまで残る。
- マップと通路・清掃車・工場は通常の0.2倍の縮尺。会社の清掃車の速度は1.28。文房具・家具・社員は上記の固有寸法を使う。
- 工場の煙突・衝突形状・排出先・迂回位置も縮尺を合わせる。排出は0.9秒を維持し、飛行中の重力倍率を0.8にする。着地後は通常重力に戻す。

会社の小物専用工場2か所は各2秒おきに、倒れても現在の穴に入る消しゴム・鉛筆・ホチキス・書類を補充する。通常工場の4分の1の寸法で開始地点付近にランダム配置し、レベル6到達で供給停止と回収解禁を行う。詳しい仕様と追加後の結果は [supply-collision-review.md](supply-collision-review.md) を参照。

## 日本風の地獄

歩くドクロ・亡者 → 鬼・石像 → 鉄の釜 → 大鬼・針の岩山 → 閻魔大王。

- 初期の198物体（工場を含む）のうち174体、約88%が歩く種類。ドクロ・亡者・鬼・大鬼をそれぞれ歩かせる。最終目標・釜・岩山・石像・工場は歩かない。
- 共通の歩行・飲み込める大きさになってからの穴からの逃走・物理落下を使う。地獄の速度は歩行0.8・逃走1.6とし、群れを追って回収しやすい仮値で始める。落下開始後は水平制御と直立制限を解除する。
- 血の池は暗い岩場に赤い池として描画し、通常の床として通行できる。池で物や穴を沈める、ダメージを与える、移動を遅くする処理は追加しない。
- 工場から補充された歩く種類は、放物線の飛行中は歩行制御を止め、着地後に歩き始める。ドクロや鬼も通常の供給候補に含む。
- 閻魔大王は赤い顔、黒い冠、金の「王」の印、ひげ、衣、机と玉座を持つ最終目標。人物を分解せず、一体の剛体で落下させる。
