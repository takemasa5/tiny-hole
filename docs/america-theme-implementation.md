# アメリカのテーマ試作

更新日: 2026-11-13

承認済みコンセプトに沿い、持ち帰り用の紙箱 → ダイナー店内 → 駐車場 → 郊外の商業地区 → 湾岸都市を試作する。最終目標は自由の女神。以前のアメリカの供給工場・清掃車の文書は旧版の記録であり、今回の成長版の動作とは区別する。

## 空間・対象と動作

- 紙箱: パンくず、ポテト、包み紙、王冠、ハンバーガー、ホットドッグ、マグカップを雑多に置く。側面はレベル4で開く。
- ダイナー: 赤いボックス席、テーブル、カウンター、冷蔵庫、鉄板コンロ。客は店内を往復して待つ。ドアはレベル7で開く。
- 駐車場: 店舗を回るドライブスルーの車列、歩行者、タイヤ、コーン、街灯。車は進路の他車で停止し、窓口に相当する経由点で待つ。ゲートはレベル9で開く。
- 商業地区: 店舗・建物と工事現場の鉄骨、道路を回る配送車、往復する買い物客。湾岸への門はレベル11で開く。
- 湾岸: 広い街区へビル・店舗・樹木・設備を配置し、幹線道路を車が走る。小舟は停泊する。自由の女神は商業地区出口の正面 `(600, 0)` に、幅180・高さ500・奥行160で置く。

12段階の穴の寸法は維持する。在庫は各レベル24個、足りなくなった場合は既存の周辺補充を使用する。物理的に落ちた物は対象レベル未満でも回収し、目標ならクリアする。人物は穴に入る大きさになって近づいた場合に逃げる。落下中は経路制御を解除する。

## 描画・当たり判定

床と道路は床テクスチャへ描き、物体の前に描かれる平面を追加しない。マグカップは底・壁・取っ手、鉄骨は柱・梁、目標は見える台座・胴・腕などの実部品から当たり判定を作る。空洞を見えない箱で塞がない。将来の物は遠方のプレビューとして置き、近傍から物理演算を有効にする。

接触なしの自然転倒全般はオーナー指示により今後の改善項目とし、今回の変更では全体対策を追加しない。

## 検証

- PC Chromium 156: シード42を矢印キーで操作し、全12段階・5空間の通過・自由の女神の物理的な回収・エジプトへの自動移行を確認。実行時エラー0件。664個・28種類を生成する。
- 客の往復・待機、車と配送車の走行をブラウザの実体で観測。
- 390×844のChromiumタッチ模擬: 移動・停止、レベル4までの壁の制限、画面内16pxの案内、リスタート、ステージ切替が成功。
- 自動テスト571件がすべて成功。1,000シードの配置・経路、全種類の見える形状と衝突範囲・実落下、空洞、4境界の開放を検証。
- ビルド・Lint・フォーマット成功。1,000シードで配置と経路が成立し、全種類の表示範囲・衝突範囲一致と実落下を検証。
- PC通し時のフレーム時間中央値は各段階約16.7ms。レベル11でp95約50msを観測しており、端末性能の保証には使わない。
