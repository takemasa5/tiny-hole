# 会社のテーマ試作

更新日: 2026-11-13

承認済みコンセプトに沿い、床の文具トレー → 別館の執務室 → 会議室・社長室 → 敷地と駐車場 → 本社地区を試作する。従来の会社限定の小物供給工場などの記録は旧版の履歴として扱う。

## 空間と動作

- 文具トレー: クリップ・画鋲・消しゴム・鉛筆・ホチキス・書類・テープを雑多に置く。側面はレベル4で開く。画鋲は見える頭部を下にして置く。
- 別館: 机・椅子・モニター・キーボード・書類棚・複合機。社員が机と複合機の前を往復して待つ。ドアはレベル7で開く。
- 会議室・社長室: 会議卓・ソファ・机・収納と社員。社長室は実際の壁と開口で分け、会議室と行き来する。ドアはレベル9で開く。
- 敷地・駐車場: 社用車・配送車・搬入台車と別館・街灯。車や台車は道路を往復・巡回し、進路が塞がると停止する。本社地区への門はレベル11で開く。
- 本社地区: 広い街区へ社屋・街路樹・設備を配置。本社は出口正面 `(600, 0)` に幅180・高さ560・奥行160で置き、見える台座と入口の柱を持つ。

12段階の穴の寸法、実際に飲み込んだ物の加点とクリア、人物が飲み込める大きさで逃げる条件、落下時の操作解除は維持する。各レベル24個の在庫と既存の周辺補充を使う。

## 描画・衝突

机の脚、椅子の脚、テープやクリップの輪、本社入口の隙間を実形状として残す。見えない支持面や大きな箱の当たり判定は追加しない。床・道路・会議室の床色は背景テクスチャへ描き、物体の前に重なる床面を追加しない。遠方のプレビューと近傍の物理演算を分ける。接触なしの自然転倒全般の対策は今回の対象外。

## 検証

- PC Chromium 156: シード42を矢印キーで操作し、全12段階・5空間・本社の物理的な回収・地獄への自動移行を確認。実行時エラー0件。663個・26種類を生成する。
- 本社は穴との接触で大きく傾いたため、既存の目標タップで1回立て直してから回収した。レベルや座標の直接変更は行っていない。検証側の時間上限を延長し、通常入力の回復操作を併用した実行として記録する。
- 社員の往復・待機、搬入台車・配送車・社用車の走行をブラウザの実体で観測。
- 390×844のタッチ模擬: 移動・停止、出口の壁、画面内16pxの案内、リスタート、ステージ切替が成功。
- 自動テスト638件がすべて成功。3ステージそれぞれ1,000シードの配置・経路、全種類の見える形状と衝突範囲一致・実落下、空洞、4境界、社長室の仕切りと社員の往復先を検証。
