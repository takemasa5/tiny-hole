## 起動

```sh
npm install
npm run dev -- --port 5173
```

PCでは `http://localhost:5173/` を開く。
iPhoneでは同じネットワークのPCが表示する Network URL を開く。
接続可能かどうかはネットワーク環境に依存する。

- 指またはマウス左ボタンで画面をドラッグすると、ドラッグした方向へ穴が移動する。
- ゲーム画面内の文字選択・長押しメニュー・要素ドラッグ・タップ時のブラウザ標準ハイライトを抑止する。ゲームのドラッグと各ボタンのタップは有効。
- PCはWASDまたは矢印キーでも移動できる。押している間移動し、キーを離すと停止する。
- 穴は画面中央にあり、成長しても画面上の大きさは一定。
- 小箱などから飲み込み、最後に青い印の付いた記念塔を飲み込むとクリア。
- 記念塔をタップすると、現在の水平位置で直立させる。普通の物をタップしても無反応。
- 右上の再開ボタンとクリア画面のボタンで、新しいランダム配置を最初から遊べる。
- 効果音は最初のドラッグ・タップ・移動キーで有効になる。右上の「音 ON / 音 OFF」で切り替えられ、再開しても選択を維持する。
- 街にいる人は歩き、穴が近づくと走って逃げる。追いついて落とすと成長ポイントになる。
- 広場・エジプトの人が落ち始めると約1.6秒のコミカルな「あーーーー」、アメリカの人は約0.7秒の「Damn it!」、たぬきは約0.5秒の「きゅーっ」が鳴る。人の声は後半ほど小さくする。音OFFの間は鳴らない。
- 制限時間と失敗条件はない。

ポイントは概算体積に比例する値を丸めたもの。穴の入りやすさは物理形状で決まり、ポイントの値とは独立する。

- 地形は約68.6×68.6の平坦な広場。初期56×56の面積を正確に1.5倍にするため、一辺を√1.5倍にした。穴全体が広場内に収まる位置へ移動を制限する。
- 現在の物量は559個（固定配置の物535個＋動く人24人）。個々の配置座標は保存・管理しない。
- 道路2本の両側にランダム生成。道路の幅・位置は描画と生成で共通の定義を使い、道路上・境界外・初期穴・他の配置地点との重なりを避ける。
- 小箱は60地点に配置し、そのうち20地点を20段積みにする（合計440箱）。同じ柱の各箱は独立した剛体・成長値を持つ。
- 積み重ねの初期間隔は高さ0.65に対して0.025。開始後は物理演算で支え合い、穴に落とせば上の箱も落下する。
- 再開ごとに新しい乱数シードを選ぶ。診断スナップショットにシードを含め、`createStage(seed)` で再現できる。これは初期配置データの保存ではない。
- 今回のポリシーは道路沿い。別のステージの配置ルールは、そのステージ制作時に追加する。
- 物理は1/60秒刻み、重力は9.81、摩擦は0.65、反発は0。
- カメラは画角44度、穴に対して高さ7.6倍・奥行6.8倍を基準とし、縦横比を補正する。
- 移動速度の上限は毎秒穴半径の7倍。指を離すと停止する。
- キー移動も毎秒穴半径の7倍。斜め方向を正規化し、Wと↑などの重複押下で加速しない。逆方向は相殺し、キーを離す・ウィンドウのフォーカス喪失・タブ非表示で保持状態を解除する。キー移動中はキー方向を優先する。
- 8px以内の揺れはドラッグにしない。500ms以内に離した操作をタップとして扱い、一度ドラッグになった操作は開始点に戻ってもタップにしない。
- 目標物の置き直しは地表または近接物の上方へ配置し、水平位置と初期の向きを維持、速度・角速度・外力をリセットする。成長値・回収数は変わらない。
- 成長は半径とカメラ距離を同じフレームで変更する。穴の表示径を維持し、約1.15秒の光の輪・28個の金色の粒子、約1.45秒のレベル表示、成長バーの発光、上昇する音で成長を祝う。
- 複数段階を一度に超えた場合は到達した段階で1回祝う。移動・物理は演出中も継続する。動きを減らす設定では粒子と輪の拡大を止め、レベル表示はフェードだけにする。
- 床は64分割の開口を持つ三角形メッシュ。穴が動くと固定床の形状を更新する。
- 床の開口に近い物を起こす。物全体の上端が地表より0.15下を通過すると、床による再支持を無効化する。
- 物全体の上端が地表より1.2下を通過してから回収・除去する。目標物も同じ判定。
- 物は壊れない箱形剛体。見た目の細部と衝突形状は一致しない箇所がある。

### 動く人・効果音の仮値と実装

- 現在の街の動く種類は人のみ。24人を他の物と同じ配置ポリシーで重なりなく生成する。
- 人は3〜6秒ごとにシード付き乱数で向きを選び、その間は直線歩行。歩行速度1.1、走行速度3.4。
- 穴の縁から3.2以内で逃走、5.2以上離れると歩行へ戻る。建物による視線の遮蔽は判定しない。
- マップの端では内側へ向きを変える。歩行中の接触は剛体同士の衝突で処理し、経路探索は行わない。
- 歩行中は直立を保ち、水平速度だけを制御する。穴に全体が入るか足元が地表より下へ落ち始めた時点で制御を解除し、自由な回転・重力で落とす。落下後は通常物と同じ回収判定を使う。
- Web Audio APIで飲み込み・成長・クリア音と、人の「あー」を合成する。外部音源・追加依存は使わない。
- 広場・エジプトの人は約1.6秒の少し高い母音を合成し、音程を軽く上下させながら後半の音量を下げる。アメリカの人は同梱音声の「Damn it!」にも同じ減衰を適用する。たぬきは約0.5秒の高い音程が下がる鳴き声。回収完了ではなく歩行から落下へ切り替わる瞬間に1回だけ鳴らす。同じ種類の同時落下では180ms以上の間隔にする。
- 大量回収時の飲み込み音は90ms以上の間隔にし、音源は最大24声。成長とクリアには短い上昇フレーズを使う。
- タブ非表示時は音を停止し、復帰後の操作で再開する。音の失敗はゲームを止めず表示し、音ボタンで再試行できる。再開・終了時は音源とAudioContextを破棄する。

## 検証コマンド

```sh
npm run build
npm test
npm run lint
npm run format:check
```

開発サーバーを起動した状態で `npm run test:browser` を実行すると、
Chromiumの通常マウスドラッグで成長からクリアまで確認し、スマートフォン画面幅・タッチドラッグ・指を離した後の停止を確認する。
Playwrightの対応ブラウザが必要。必要な場合は `npx playwright install chromium` で導入する。

開発モードだけに、読み取り専用の `window.__hole.snapshot()` を公開する。
テストはこれで位置・状態・描画サイズを観察するが、回収・成長・クリアを直接操作しない。
本番ビルドにはこの診断口を公開しない。
