## 空間・配置・成長

12段階の穴半径・成長ポイント、穴の画面上の大きさ、平面上の移動を維持する。小さい空間を大きい空間が囲み、成長前に見上げた花や遊具を後から飲み込める。位置・寸法・数・境界の開放条件は試作の仮値。

| レベル | 場所           | 主な回収対象                                       | 出口                           |
| ------ | -------------- | -------------------------------------------------- | ------------------------------ |
| 1〜3   | 花壇の足元     | 種、小石、花びら、落ち葉、花、じょうろ             | レベル4で花壇の縁が開く        |
| 4〜6   | 公園の遊び場   | ボール、バケツ、三輪車、ベンチ、すべり台、ブランコ | レベル7で遊び場の門が開く      |
| 7〜8   | 公園全体       | 木、ベンチ、露店、噴水                             | レベル9で公園の門が開く        |
| 9〜10  | 公園前の商店街 | 露店、街灯、商店、配送車、ビル                     | レベル11で記念広場の門が開く   |
| 11〜12 | 記念広場と街   | ビル、会館、巨大な記念塔                           | 記念塔が実際に落ちきるとクリア |

- 各レベルの成長用在庫は24個で、2〜3種類を混ぜる。通常は同レベルを約12個集めると次へ成長する。地獄の捕獲必須ルールは適用せず、静止物だけでもクリアへ進める。
- 花壇は小物を雑多に置き、2本の大きな花を固定の比較対象として残す。遊び場の大きなすべり台・ブランコ、公園の噴水・木、商店街の店にも固定の位置と寸法を与える。
- 合計665個・23種類。成長用在庫264個、移動対象48体、遊び場・公園・商店街の環境物88個、終盤の32街区に256個、固定の比較対象8個、記念塔1個。
- 終盤は3200四方の街へ広がる。道路を空け、各街区に店・ビル・木・街灯を配置する。街の四方に物があり、中央の塔だけを残す配置にしない。
- 記念塔は寸法190・540・190で、商店街の東の出口正面 `(600, 0)` に立つ。レベル11の出口から近づく段階で見上げ、同じ位置の塔を最終段階で飲み込む。目標と固定の比較対象・各街区の代表建物は先に表示する。
- 境界は花壇の縁と公園の柵・門。地面に固定し、接近すると16pxの画面案内で開放レベルを示す。
- 成長用在庫が不足すると、穴の近くと他の物との重なりを避けて空いた元の配置位置に同種の在庫を補充する。地獄でも使う2秒周期の処理を共用し、箱から無関係な物を排出する補充は行わない。
- 実際に飲み込めた物は目安レベル未満でも加点し、記念塔も実際の回収でクリアする。

## 動作と形状

- 人は花壇の周り、公園内、商店街の歩道を巡回して一息つく。配送車は公園の作業路・商店街・街路を走り、経路上の停車点で停止する。巡回路を静止物の配置から予約し、壁・内側の空間を横断しないようにする。
- 人の寸法はどの場所でも0.55・1.8・0.45を維持する。穴が成長すると、人が相対的に小さくなる。穴に入る外形になってから接近すると逃げ、まだ入らない場合は散歩を続ける。
- 人・車は落下開始後に行動制御を解除する。模型の足や車輪を動かすために物理演算を無効化しない。
- バケツ・噴水は壁と底を別部品とする。ブランコの支柱の間、露店の脚の間、記念塔の入口にも空間を残す。顔や窓の描き込みは厚みのない図形とし、見えない支持面を作らない。
- 公園の柵は支柱・横桟を表示し、その部品ごとに当たり判定を作る。支柱の間を透明な箱型の壁で塞がない。閉じた門は見える板の形状を使う。穴の移動範囲の開放は既存の境界処理で行う。

## 描画・物理演算の範囲

床の土・草・舗装・道路は各空間のテクスチャへ描き、既存の背景描画順序と透過・位置補間の修正を引き継ぐ。小物の上に地面を後描きしない。柵の支柱は描画をまとめるが、当たり判定は実際の部品を維持する。

遠方の街並みは見た目を残し、環境物の剛体は穴の近傍で有効化する。未開放の空間では物の物理演算を始めない。落下中・透過中・他の物との接触中の物は一律に停止・退役させない。既存の成長用在庫と衝突部品のキャッシュは、広場の種類をキーに含める。
