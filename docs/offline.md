# 端末に保存して遊ぶ

更新日: 2026-10-26

公開URL: [HOLE](https://takemasa5.github.io/tiny-hole/)

オーナー確認により、iPhoneの「ホーム画面に追加」とPCのアプリとしてのインストールで保存するPWA方式を採用した。4ステージ、物理演算、モデル、効果音・英語の声を保存し、準備完了後はサーバー停止中や機内モードでも起動・プレイできる。プレイ途中の進行を保存する機能は今回の範囲に含めない。

## iPhoneで保存する

1. 通信できる状態で、HTTPSで配信した公開版をSafariで開く。
2. 画面左上に「オフライン準備完了」と表示されるまで待つ。
3. Safariの共有メニューから「ホーム画面に追加」を選ぶ。
4. 追加したアイコンから通信できる状態で開き、もう一度「オフライン準備完了」を確認する。ブラウザとホーム画面のアプリで保存領域が分かれる場合にも備える。
5. 以後はそのアイコンから起動する。サーバーへの接続は不要。

左上の保存状態をタップすると保存方法を確認できる。音声は従来どおり最初の操作で有効になる。

## PCで保存する

HTTPSの公開版で「オフライン準備完了」を確認し、ブラウザのアプリのインストール、またはSafariの「Dockに追加」を使う。対応ブラウザではゲーム内の保存案内にも「この端末にアプリを保存」が表示される。保存後はそのアイコンから起動できる。

通常の「HTMLファイルとして保存」は今回の保存方式ではない。ブラウザ・端末の保存データを削除したときや、容量不足でデータが消去されたときは、接続して保存し直す必要がある。

## 初回保存の配信とローカル確認

初回保存にはHTTPSが必要。LAN内のIPアドレスへHTTPで接続した開発ページからは、iPhoneのオフライン保存はできない。開発用サーバーでは保存処理を動かさず、その旨を表示する。

PCのローカル確認は以下で行う。`localhost` は開発用の例外として利用できる。

```sh
npm run build
npm run preview -- --port 4173
```

`http://localhost:4173/` を開いて準備完了後、サーバーを停止し、同じURLを開き直す。iPhoneの初回保存には、生成した `dist/` をHTTPSの静的ホスティングへ配置する。配信先のサブディレクトリにも対応し、バックエンドは不要。

オーナー承認によりGitHub Pagesを公開先に採用する。`.github/workflows/pages.yml` は `master` へのpush時にテスト・Lint・フォーマット確認・ビルドを行い、`dist/` だけを公開する。公式Actionsは確認したリビジョンへ固定し、Node.js 24で実行する。

## 保存・失敗・更新の方針

- ビルド時に配布する全ファイルを自動で一覧化し、内容のハッシュを保存版の識別子にする。RapierのWASMはJavaScript内へ同梱済み。
- 必要なファイルをすべて保存できた場合だけ、準備完了を表示する。保存失敗時は案内から再試行できる。ゲーム本体のオンライン利用は継続できる。
- 新しい版は裏で保存して待機する。プレイ中に自動で再起動せず、案内の「新版に更新して再起動」で切り替える。この操作ではゲームは最初から始まる。
- 更新に失敗しても、以前の正常な保存版を消さない。有効化時にこのゲームの同じ配信パスの旧版だけを削除し、別のアプリの保存には触れない。

## 検証

```sh
npm test
npm run build
node checks/offline.mjs
```

自動テストでは保存成功・失敗、通信不要のHTML・JavaScript・音声の取得、更新の待機、キャッシュの削除範囲を確認する。ブラウザ確認では本番ビルドをサブディレクトリに配信し、通常のHTTPキャッシュを削除したうえでサーバーを停止し、通信を遮断して別のページから起動する。iPhone実機でのホーム画面からの起動・機内モード確認は別途必要。

2026-10-26のChromium 156.0.8078.4確認では、10リソースを保存し、サーバー停止後の別ページからの起動、4ステージの切り替えとキー操作、390×844でのタッチ入力・案内表示、音声の取得・デコードと効果音の再生に成功した。新版の待機から手動更新、音声ダウンロード失敗の検知と再試行も確認し、実行時エラー0件。結果は [offline-check.json](../reports/offline-check.json)、案内の見た目は [offline-mobile.png](../reports/offline-mobile.png)。WebKit・iPhone実機は未確認。
