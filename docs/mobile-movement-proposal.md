# スマートフォンの継続移動操作の試作

2026-11-17の提案を、2026-11-18のオーナーの「仮想スティック対応してみてください」で試作へ採用。

ブランチは `codex/mobile-stick-trial-20261118`。開始点は、おもちゃの提供BGMを含む `301ef07`。ゲーム画面で操作できる試作を追加する。

## 改修前のコードで確認したこと

- `src/game/gesture.ts` は、指の移動差分を返す。`runtime.ts` はその差分で地面上の移動先を延ばし、穴を移動先まで進める。
- 指を止めると移動先が更新されず、穴がそこへ到達すると停止する。指を離した場合も、移動先を現在の穴の位置に戻して停止する。
- キーボードは押している間、物理ステップごとに進行方向を更新するため、方向キーを保持すれば継続移動できる。
- 穴の最高速度は半径の7倍/秒。赤鬼のダッシュはこの97.2%、小鬼は94.5%、青鬼は90%が基本となり、減速区間や足場・旋回の条件が加わる。既存の `tests/hell-stage.test.ts` にも速度比の検査がある。
- 従って、持ち替えや指の静止で追跡が途切れる操作は不利になる。今回の報告と整合するが、iPhoneでの `pointercancel` 発生や入力途切れの直接計測は未実施。

## 比較

| 案                                     | 指を止めたとき               | 追跡との相性                           | 主な課題                                           |
| -------------------------------------- | ---------------------------- | -------------------------------------- | -------------------------------------------------- |
| 触れた場所に出る仮想スティック（推奨） | 倒した状態を保てば進み続ける | 継続移動しながら方向と速度を調整できる | 最大入力へ届きやすい距離と、微調整範囲の調整が必要 |
| 画面下の固定方向パッド                 | 押している方向へ進み続ける   | 追い続けやすい                         | 方向の切り替え、細かい狙い、常設UIの占有面積       |
| スワイプ後の自動走行                   | 指を離しても進み続ける       | 長距離を追いやすい                     | 別の停止操作が必要になり、狙った所で止まりにくい   |
| タップした場所への移動                 | 指定地点へ着くと停止する     | 静止物の回収向き                       | 逃げる相手には繰り返し位置を指定する必要がある     |

## 採用した操作

1. ゲーム画面の操作しやすい場所へ指を置く。その位置をスティックの中心にする。
2. 少しずらすと、その方向へ移動する。操作中だけ、指元に半透明の輪と入力位置を表示する。
3. 指をずらした位置に置いたままでも移動を続ける。方向を変えるときだけ指を動かす。
4. 中心へ戻すと停止する。指を離した場合も即停止する。

入力は毎物理ステップで速度へ変換する。小さく倒せば微速、十分に倒せば現行の最高速度になる。斜め入力でも最高速度は同じにし、見えている画面の方向と進行方向を合わせる。

初期の試用値は、中心付近の8 CSS pxを停止範囲、中心から36 CSS pxで最高速度とする。半透明の輪は操作中だけ表示し、最大入力では色を変える。鬼を追うときの最高速の保ちやすさ、小物の微調整、画面端に近い位置からの操作を実機で確認して数値を調整する。

## 試作の範囲

- タッチ入力で試す。PCのマウスドラッグ・WASD・矢印キーは既存方式を利用する。
- 穴の最高速度・成長・敵の速度は現行値を使い、操作方法の効果を比較する。
- タップの小さな揺れとスティック操作を分け、既存の目標物タップによる立て直しを利用できるようにする。
- 指を離す・入力キャンセル・画面非表示・フォーカス喪失・クリア・再開・ステージ変更では継続入力を解除する。
- メニューの「タッチ操作」で「仮想スティック」「ドラッグ」を切り替える。初期値は仮想スティック。選択は再開・ステージ変更時も保持するが、ページを再読み込みすると初期値へ戻る。メニューを開いた時もスティック入力を解除する。

## 検査と試遊の観点

- 1回の小さい指の移動の後、指を静止させても移動が続き、離すと止まる。
- 上下左右・斜めで追跡でき、切り返しと微速が使える。
- 地獄で小鬼・赤鬼・青鬼・閻魔を追い、持ち替えの回数と、狙って止まれるかを既存ドラッグと比較する。
- 小物の回収と狭い出口の通過、目標物のタップ、画面端からの操作を確認する。
- スマートフォン幅のタッチ模擬とiPhone実機の結果を分ける。最終的な使いやすさはiPhone実機の試遊で判断する。
