## 今回のルール

全8ステージで穴の直径16cm相当から始まり、12段階で最大320m相当へ成長する。ゲーム内寸法であり、実物を精密に再現するものではない。穴の画面上の大きさ、物理演算による傾き・落下、制限時間・失敗条件なし、クリア後約3秒で次ステージへ進むルールを維持する。

対象レベルは配置・在庫の目安とする。傾いて穴へ落ちきった物は対象レベル未満でも回収・加点し、最終目標ならその時点でクリアする。最終目標の回収にレベル12を要求せず、クリア時の成長も通常のポイント計算に従う（2026-11-06 オーナー確認）。

| レベル | 穴の直径 | 対象の中心                             |
| ------ | -------- | -------------------------------------- |
| 1      | 0.16     | 消しゴム・ナット・木の実・ビーズ・小骨 |
| 2      | 0.28     | 鉛筆や一回り大きな小物                 |
| 3      | 0.5      | 文具・小箱・小さな荷物                 |
| 4      | 0.9      | 箱・浮き・食べ物・積み木               |
| 5      | 1.6      | 椅子・樽・小さな動物                   |
| 6      | 3        | 人・机・屋台・作業道具                 |
| 7      | 6        | 車・コンテナ・家具・鬼                 |
| 8      | 12       | 家・船・大きな設備                     |
| 9      | 24       | 倉庫・大型の木・遺跡                   |
| 10     | 48       | ビル・クレーン・大型設備               |
| 11     | 96       | 大型建造物・巨大ヒーローと怪獣         |
| 12     | 320      | ステージ固有の巨大目標                 |

各段階の物の寸法は、その大きさで実際に落とせるように調整する。序盤の人や家具を不自然に巨大化し続ける代わりに、中盤から建物・設備へ対象を移す。巨大物の落下時間を尺度ごとにそろえるため、重力を穴半径に応じて調整する。物を座標の置き換えで消す方式にはしない。

会社は社長を途中の対象にし、最終目標を本社ビルへ変更。港はクレーンを途中の対象にし、タンカーを最終目標にする。他の最終目標は記念塔・森の大樹・自由の女神・ピラミッド・巨大ロボット・閻魔大王を巨大な寸法にする。巨大ヒーローは独自の簡易モデルで、特定の既存キャラクターのモデルは採用しない。

## エリアと配置

| エリア       | 開放レベル | 範囲の半幅 | 内容                     |
| ------------ | ---------- | ---------- | ------------------------ |
| 足元         | 1          | 2.4        | 開始地点付近の小物       |
| 仕事と暮らし | 4          | 18         | 人・家具・作業場         |
| 街と設備     | 7          | 180        | 道路・家・コンテナなど   |
| 巨大な世界   | 10         | 1600       | ビル・大型設備・巨大目標 |

同じ世界座標上で行ける範囲が広がる。四方向の境界にコーンと低い柵を固定座標・固定サイズで置き、穴の半径を含めて移動を制限する。近づくと画面内に16pxの文字で「この先はレベル○で進めます」と表示する。次のエリアの入口在庫を準備してから開放し、開放後は往復できる。会社も平面のオフィス周辺から社屋へ広がり、階段・天井・階層移動は導入しない。

物の種類はステージごとのカタログで指定し、サイズ帯ごとに複数種類を使う。通常在庫はレベル1〜11に各24個。動く物がある段階でも、静止・停泊の在庫だけで必要ポイントの1.5倍以上を確保する。配置は経路と物が重ならない作業場単位の配置とし、見た目の向きはシードで変える。

## 動きと透過

- 車は表示された道路を巡回し、角で短く停止する。汽車は同じ経路方式で線路を巡回する。
- 社員・作業員・動物は仕事場や餌場の決まった地点間を移動して休憩する。兵隊・亡者は巡回する列を構成する。すべての個体を歩かせず、静止した在庫も残す。
- 人や動物は飲み込めるサイズになってから回避する。車と汽車は自由な方向へ逃げず、経路を維持する。
- おもちゃの街には巨大ヒーローと怪獣を1組置く。接近・構え・攻撃・後退を繰り返し、相手が回収されたら周囲を探す。HPやダメージ、建物の破壊は導入しない。
- 小舟・タンカーは停泊して自走しないが、近傍では他の物と同じ動的剛体として支える。穴が支えを失わせると、サイズや対象レベルに関係なく傾く。水面は水色の通常床として穴も進める。浮力と航海は導入しない。
- 支持を失って落下した後は行動制御と直立制限を解除する。
- 現在の姿勢の衝突形状が穴に入る物は透過しない。入らない大物のうち、カメラから穴の中心と周囲8点のすべてを実際に遮る物だけを半透明にする。カメラが外枠の内側に入ったという理由だけでは透過しない。短い猶予と補間で復帰させ、透過中も物理・回収条件は変えない。

## 生成・休止・撤去

初期に全配置の軽い定義を作り、詳細モデルは現在と次のレベルから順次準備する。おもちゃの試作では、現在エリアの見た目を先に準備し、同じエリア内の成長による突然の追加を抑える。将来の代表物と最終目標は予告表示する。生成は通常1フレーム4個までに分ける。描画と、剛体を持つこと・行動することは分けて管理する。

穴と物の外形に余白を加えた近傍で、レベルと大きさに関係なく動的剛体として物理を有効にする。近くの予告モデルは正しい描画と衝突形状に切り替える。遠方で床に安定し、他の物に触れていない物は位置・姿勢を保って休止する。落下中の物は停止しない。小さすぎる物は、6レベル以上前・表示尺度が十分小さい・十分遠方・落下や透過の対象外、他の物と接触していない、という条件で撤去する。撤去に加点せず、回収・撤去済みのIDを再生成しない。

物量管理では固定・睡眠・活動中の剛体を分けて観測する。150〜250個という提案時の物量は性能保証値ではなく、今回も実測結果と組み合わせて評価する。

各段階に見える補充箱を置く。次の成長に必要な現在レベルの静止在庫が減った場合は、2秒間隔で空き場所を探し、箱の上から物を放物線で排出する。補充箱の寸法は次の段階を目安にするが、回収レベルによる固定はせず、他の物と同じ物理演算を適用する。古いレベルや未開放先の在庫で現在の不足を満たしたと扱わない。最終レベルでは補充を終える。旧版のランダム工場排出と清掃車による場外押し出しは今回の実行経路では使わない。

オフライン保存は既存の仕組みを使う。プレイ中の段階生成に外部通信は不要。再開・ステージ切替で物理世界・描画・行動・透過状態を破棄する。

## 確認方法

- `npm test`: 既存試験と、全8ステージの在庫・寸法・段階成長・行動切替・透過・実際の物理落下を確認。
- `npm run build` / `npm run lint` / 対象ファイルのPrettier確認。
- 開発サーバーで `node checks/growth-flow.mjs`。読み取り用のスナップショットと通常の入力で成長・ゲート・最終目標を確認する。`--stage=harbor` のように絞れる。
- `window.__hole.snapshot()` は開発時のみ公開する観測用API。位置・レベル・得点を変更するAPIは設けない。

PC Chromium、WebKit、iPhone実機の結果を区別する。ブラウザ自動操作の経過時間を、人のプレイ時間や面白さの評価として扱わない。
