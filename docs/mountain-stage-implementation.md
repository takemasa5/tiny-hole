## 空間と成長

12段階の穴半径・成長ポイント、平面上の移動、穴の画面上の大きさを維持する。小さい空間を大きい空間が囲み、成長すると前にいた場所を見下ろせる。寸法・個数・速度・開放レベルは試作の仮値。

| レベル | 場所             | 主な対象                                                       | 出口                          |
| ------ | ---------------- | -------------------------------------------------------------- | ----------------------------- |
| 1〜3   | 木の根元の草むら | どんぐり、小枝、小石、松ぼっくり、落ち葉、キノコ、シダ         | レベル4で根元の小道が開く     |
| 4〜6   | 森のキャンプ場   | ランタン、やかん、椅子、テント、クーラーボックス、テーブル、薪 | レベル7でキャンプ場の門が開く |
| 7〜8   | 山里と林業ヤード | 丸太、切り株、丸太置き場、山小屋、トラック                     | レベル9で林業ヤードの門が開く |
| 9〜10  | 深い森           | 杉、広葉樹、苔の岩、鳥居                                       | レベル11で聖域の入口が開く    |
| 11〜12 | 巨木の聖域       | 巨木、祠、岩、最終目標の大樹                                   | 大樹が実際に落ちきるとクリア  |

- 成長用在庫は各レベル24個、計264個で、各段階に3種類を混ぜる。同レベルを約12個回収すると次へ成長する。静止物だけでも成長でき、動物の捕獲は必須にしない。
- 根元の切り株とシダ、キャンプ場の大きなテント・テーブル、ヤードの山小屋・丸太置き場、森の木・岩、聖域の鳥居・祠を固定の比較対象として置く。成長前に見上げた同じ物を、後から飲み込める。
- 最終目標は寸法200・680・200の「森の大樹」。深い森の東の出口正面 `(600, 0)` に置き、レベル11の出口から近づく段階で巨大さを見せる。目標・比較対象・動物の生活場所と各木立の代表の木は先に表示する。
- 根元は小物を雑多に、キャンプ場は道具とテント、ヤードは小屋と積み丸太、森は木立として配置する。終盤は32か所の位置を少しずつずらした木立に192本の木と64個の岩・シダを配置し、四方へ森を広げる。
- 全体は31種類・691個。成長用264個、移動対象40体、環境物88個、終盤の木立256個、固定の比較対象10個、巣と餌場8個、独立した積み丸太24本、大樹1本。
- 境界は地面に固定した縁と木柵・門。接近すると16pxの画面案内で開放条件を示す。
- 在庫不足時は、穴の近くと他の物との重なりを避けて空いた元の配置位置へ同種を補充する。既存の2秒周期を使い、無関係な箱を供給源として追加しない。
- 目安レベル未満でも、物理的に飲み込めた物は加点する。大樹も実際に回収された時点でクリアする。

## 動物と林業

- たぬき4体、鹿14体、きつね6体を配置する。各グループに巣と木の実の茂みを置き、その入口と餌場を往復して一息つく。まだ穴に入らない大きさなら通常行動を続け、入る外形になって接近すると逃げる。
- 動物の大きさは場所ごとに拡大しない。たぬきは0.5・0.65・0.8、鹿は0.8・1.9・1.5、きつねは0.45・0.75・1.2。穴の成長で相対的に小さくなる。
- 林道には丸太を載せたトラック16台を配置する。林業ヤード・深い森・聖域外周の道を走り、経路上の停車点で2秒停止する。車載の丸太は車体と一体の形状とし、荷下ろしの自動生成は行わない。
- 24本の積み丸太は、車載の丸太とは別に、ヤードの4か所へ6本ずつ置く。1本ごとに別の剛体として3段に井桁積みし、支持を失うと傾き・転がり・崩落が起きる。
- 動物とトラックの経路は静止物の配置から予約し、壁・内側の空間を横切らないようにする。落下開始後は行動制御を解除する。

## 形状・描画・物理

テントは左右の布・底・棟木で構成し、入口の三角形を見えない板で塞がない。テーブルの脚、山小屋の入口と内部、丸太置き場の隙間、鳥居、動物の巣も部品の間を空ける。木は幹・根・枝・葉の塊を別形状とし、モデル全体を1つの箱にはしない。全種類の衝突範囲を実際の表示モデルから作る。

初回の通し確認では、根の接地位置に差があり、幹が地面に接しないまま木が傾く問題が見つかった。根を水平に広げ、見える根の下面と幹の平らな底を同じ地面へ合わせた。木を物理的に固定せず、接地する形状そのものを直している。通常の木・巨木・大樹について、平地の直立と実際の穴半径・重力で支持を失った後の落下を追加検査した。

2026-11-13の草（シダ）の転倒対策では、既存の8枚の葉の開きを少し抑え、各葉の最下部を同じ接地面へ合わせた。接地点が根元の一点に集まらないよう、見える葉の角度・配置だけを調整して支えを分散する。全体の指定寸法と物の配置は維持する。表示モデルと同じ8部品から当たり判定を生成し、追加の台座・不可視形状・姿勢固定・吸引力は使わない。地面上では安定し、穴で足場を失うと通常の物理演算で傾き・落下する。

床の土・草・落ち葉・林道はテクスチャに描き、既存の背景描画順序を維持する。手前の遮蔽物だけの透過、位置・カメラ補間を引き継ぐ。小川の模様も床の絵柄であり、移動は平面のまま、ダメージ・失敗条件は追加しない。

遠方の木立は見た目を残し、環境物の剛体は穴の近傍で有効にする。未開放の空間では物の物理演算を始めない。落下中・透過中・他の物との接触中の物は一律に停止・退役させない。種類ごとの衝突形状をキャッシュする際は山の種類もキーに含める。
