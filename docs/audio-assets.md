# 音声素材

更新日: 2026-11-16

専用ブランチの追加効果音・逃げ声と、おもちゃ以外のBGMはWeb Audioで合成する。[曲と試聴の案内](audio-effects-trial.md)。

## おもちゃのよふかし

2026-11-16、オーナーがGoogle Flow Musicで作成して `temp/おもちゃのよふかし.m4a` に置いた曲を、おもちゃステージへ採用して試す。

- 配布用: `public/audio/toy-night.m4a`。元のファイルと同じ内容をコピーし、再圧縮・切り取りはしない。
- 元音源: AAC、ステレオ、48,000 Hz、約178.048秒（2分58秒）。
- 最初のゲーム操作から読み込み・デコードして再生し、曲全体をループする。曲末の余韻や無音はそのまま使うため、継ぎ目の聴感調整は試遊後に判断する。
- BGMのOFF／ON、全音ミュート、非表示からの復帰は停止位置から再開する。「最初から遊ぶ」とステージを入り直す場合は先頭から開始する。
- 初期のBGMゲインは0.12。重要な効果音・逃げ声の際は一時的に約34%へ下げる。ミックスの聴感はオーナーの試遊で調整する。
- 読み込み中のミュートやステージ変更でも、完了後に勝手に再生しない。取得やデコードの失敗は既存の音エラー表示と再操作による再試行で扱う。
- 基準パスに従って同一サイトから取得する。既存のオフライン配布物一覧へ自動的に含まれ、追加サービスへ接続せず再生する。

### 2026-11-16の検証

- 37ファイル・678テスト、型検査、ビルド・Lint・変更ファイルの整形検査が成功。既存の100シード配置テストはブラウザ並行実行時に時間超過し、検査を単独で再実行して全件成功した。
- PC Chromiumで実ファイルのデコードと非ゼロ音声出力、重複のない再生、停止位置の維持、途中再開、全音ミュート、ステージ変更での停止、再開時の先頭再生、読み込み中のミュートを確認。
- ループの継続は同じ再生クラスに0.25秒の音声を渡した短縮検査で確認。曲全体の繰り返しの聴感は試遊で判断する。
- ビルドした配布物を保存し、サーバー停止・HTTPキャッシュ消去後も全8ステージを起動でき、おもちゃのAACをService Worker経由で取得・デコードできた。
- 記録: `reports/toy-music-2026-11-16/`。iPhone実機・WebKitは未確認。

## 従来の英語音声

`public/audio/american-fall.wav` は、オーナーが指定した「Damn it!」をmacOS標準の男性音声合成（Daniel / en_GB）で生成した試作用の声。モノラル・44,100Hz・16bit PCM、約0.70秒。外部サービスや追加依存は使わない。

生成コマンド:

```sh
say -v Daniel -r 125 -o public/audio/american-fall.wav --file-format=WAVE --data-format=LEI16@44100 'Damn it!'
```

ゲーム内では子音を切らないように前後の余白を保ってWeb Audioで再生する。セリフの前半は音量を保ち、後半で下げる。同じ波形をブラウザへ配布するため、プレイ中に端末の読み上げ機能は使わない。

初版はFred / en_US・145語/分・22,050Hzで生成した。オーナーから「Damn it!と聞こえない」との評価があったため、声を替えて125語/分で再作成し、英語用の減衰を遅らせた。
