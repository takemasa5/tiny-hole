# 成長を実感できるオブジェクトの追加案

2026-11-06 / 状態: 検討案。おもちゃのみ、オーナー承認で[テーマ・種類・配置・行動の試作](toy-stage-trial.md)を実装。他の7ステージの候補は未採用。

## 方針

同じ種類のモデルを段階ごとに大きくして並べる方法を減らし、新しいレベルでは名前・形・役割が異なる物へ対象を移す。大きさを比較するため、以前の代表物も同じ寸法のまま一部を残す。例えば「ナット→バケツ→作業員→フォークリフト→コンテナ→倉庫→船」と進め、巨大なナットや巨大な木箱で終盤を埋めない。

各レベルの主役を2〜3種類、その前後のレベルの物を合わせて4〜6種類程度から試す。個数を増やすことより種類と形の違いを優先し、現在の段階生成・近傍の物理稼働・小物撤去を使う。

物の導入レベルは配置上の目安にする。高さや長さだけで回収を禁止せず、姿勢と衝突形状によって実際に落ちるなら回収できる。細長い物を傾けて飲み込む楽しさを残す。

## 港の12段階を先に具体化する案

| レベル | 主役の候補                             | 見た目・動きで表す違い             |
| ------ | -------------------------------------- | ---------------------------------- |
| 1      | ナット・小さなボルト・釣り具の部品     | 金属や小物の形を近くで見分ける     |
| 2      | ペン・工具・飲料缶                     | 細長い物を傾ける、円柱を転がす     |
| 3      | 釣り具箱・弁当箱・ロープ束             | 箱と巻いた物で輪郭を変える         |
| 4      | バケツ・浮き・小さなごみ箱             | 容器や円柱の大きさを感じる         |
| 5      | 樽・作業員・手押し台車                 | 人との比較と、仕事の動きを出す     |
| 6      | パレット・大きな木箱・作業台           | 幅の広い物や積荷を崩す             |
| 7      | フォークリフト・小型トラック・コンテナ | 道路走行と荷捌きの場面を作る       |
| 8      | 釣り船・漁船・小さな倉庫               | 船体の長さと建物の高さを比較する   |
| 9      | 大型倉庫・港の管理棟・貨物車両         | 以前の車やコンテナを小さく見せる   |
| 10     | クレーン・大型漁船・フェリー           | 高い物と長い物で飲み込み方を変える |
| 11     | 大型フェリー・造船設備・大きな港湾施設 | 終盤の目標との距離感を出す         |
| 12     | タンカー                               | 最終目標を実際の物理落下で回収する |

寸法は名前と形に合わせて個別に決める。表のために車や人を数十メートルへ拡大したり、特定レベルまで物を固定したりはしない。船の長さと穴の直径が一致しなくても、幅・高さ・傾きによって入る場合があるため、物理で確認して配置と成長ポイントを調整する。

## 追加する順序

1. 港のフォークリフト・トラック・倉庫・船の違いを作り、1ステージで効果を試す。
2. 会社の小物・家具・屋外設備を分け、同じモデルの拡大に依存する箇所を減らす。
3. 他ステージは、各サイズ帯で最も似通っている2〜3種類を入れ替える。
4. 1段階前の代表物が小さく見えるか、次の段階の物が新しい目標に見えるかを実際に遊んで確認する。

モデルの追加に先立ち、今回の透過・境界案内・物理支持の修正を試遊で確認する。今回の実装ではこの候補を自動採用しない。
