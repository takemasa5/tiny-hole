作業員は飲み込める大きさの穴が近づくと逃げる。落下後は行動制御を解除する。船の巡回・漂流や浮力は追加しない。水面は平らな床の見た目であり、新しい移動制限は設けない。

## 吊り荷・当たり判定

荷役クレーンの柱・梁と吊り荷は別の物体。クレーンが支えている間は、荷物の剛体と表示位置を同じ上下運動で動かし、見えるケーブルの下端も荷物の上面に合わせる。クレーンが落下・消失すると荷物の制御とケーブル表示を解除し、重力・衝突へ戻す。剛体ロープの完全な物理再現ではなく、荷役動作の試作である。

工具の輪、スパナの口、パレットの隙間、フォークリフトの爪やマスト、クレーンの脚の間を不可視の箱で塞がない。床と道路・水面は背景のテクスチャへ描く。成長・透過・物理範囲の制御は既存方式を使う。接触なしの自然転倒全般は今回の対象外。
