# ヒーロー・怪獣の転倒判定と対戦モーション

更新日: 2026-11-14

モデル更新後の転倒報告を受け、2体の落下開始判定と、実際の対戦を直接見られる開発用画面を追加した。その後、オーナーが接近時の高速な振り向きを確認したため、対戦中の移動を止め、両腕で交互に叩く動きと、両腕を上げて逃げる動きへ変更した。モデル形状・配置・成長条件は維持する。

## 修正した判定

従来の2体は共通の移動物と同じ判定で、次のいずれかで落下中へ移り、直立保持が解除されていた。

- 穴が外接箱と重なる。足が地面に支えられているかは問わない。
- モデルの最下部が床から一定量沈む。穴が近くにあるかは問わない。

そのため、穴から離れた場所での接触による一時的な沈み込みや、空の四隅を含む外接箱への接近でも転倒する経路があった。2体については、既存のエジプトの神々・地獄の鬼と同じ「穴と重なり、最下部が実際に沈んだとき」に落下へ移す。沈み込みのしきい値は従来の姿勢保持対象と同じ `max(0.01, 穴半径 × 0.03)`。

地面に支えられる間は、従来からある移動時の直立保持を続ける。実際に足場を失えばその保持を解除し、傾き・落下は通常の剛体物理へ渡す。不可視の支持面・姿勢の強制的な置き直し・吸引・追加の台座は導入していない。共通の他の移動物の判定は維持する。

シード42の平地・街では、修正前でも数秒の通常対戦は直立を保っていた。オーナーが見た転倒をそのまま再現したと断定しない。回帰テストでは、遠い穴で1単位沈み込む条件と、穴が外接箱に触れるだけの条件で誤って落下へ移ることを修正前に再現し、修正後に防止できることを確認した。

## 対戦・回避のモーション

- 相手がいる間は、相手へ接近する移動と元の位置へ戻る移動を止め、水平速度0で相手を向く。元の位置から25離れた境界で、相手へ向く処理と帰る処理が交互になっていた高速旋回を防ぐ。2体がほぼ同じ位置にあるときは、それまでの向きを保つ。
- その場で左右の腕を交互に上下させ、ポカポカ叩く動きにする。右腕と左腕は半周期ずらし、約1.05秒で左右一巡する。
- 穴へ入る大きさで穴が近づくと、両腕を上げて小さく揺らし、従来の逃走速度・方向で逃げる。音声・HP・ダメージは追加しない。
- 相手が回収された後の周辺探索は従来のまま。探索中は腕を通常姿勢へ戻す。落下中も両腕の全回転を通常姿勢へ戻し、剛体の形状と表示を一致させる。
- 腕の演出は `toy-character-visuals.ts` の `animateToyCharacter` を通常ゲームと検証で共用する。
- 肩ではモデルの縦・横・奥行きの異なる縮尺を相殺してから腕を回し、大きく振っても拳・手の形と辺の長さを保つ。通常姿勢のモデル寸法と当たり判定は維持する。

## 対戦の見方

開発サーバー起動中に [対戦確認画面](http://localhost:5176/checks/toy-battle.html) を開く。実際の `startGame` と同じ街・配置・剛体・対戦・描画処理を、開発用の初期状態と固定カメラで動かす。モデルを並べた別のアニメーションではない。

- 初期状態はレベル10・穴半径24・シード42。穴は2体から離した位置に置く。
- 待つと、その場で両腕を交互に振る対戦が見られる。対戦中に自ら移動しない。ダメージ・HP・建物の破壊は追加しない。
- WASD・矢印キーで穴を動かせる。「同じ配置でやり直す」で再開する。
- `?level=9` / `?level=11`、`&seed=7` のように確認条件を指定できる。レベル11の入る大きさの穴が近づくと対戦から回避へ移る。
- 通常ページのゲームはレベル1から始まり、従来のカメラを使う。この初期状態とカメラは `import.meta.env.DEV` かつ明示した確認画面でのみ有効。配布ビルドには確認用HTMLも初期状態も含まれない。

## 検証

- 自動テストは653項目・35ファイルを確認（`npm test -- --maxWorkers=4 --testTimeout=20000`）。両腕と静止対戦を実装した時点では全653件が成功した。肩の縮尺補正後の全体実行は652件成功・会社の1000シード検証1件が時間超過（約66秒、制限60秒）となり、その1件を単独で再実行して約13秒で成功した。値の不一致による失敗はない。既存テストの60秒制限や設定ファイルは変更していない。
- 転倒対策の追加7件に加え、2体それぞれの静止対戦・25の境界での旋回防止、両手の上下関係が交互に変わること、腕を振っても手の辺長が変わらないこと、回避時に両手が肩より上へ上がること、落下時に両腕と全体外形が通常姿勢へ戻ることを追加4件で確認した。
- Chromium 156でレベル9・10・11、シード1・7・42の9条件を確認。最終版は約12.35秒・37回の観測で、2体とも水平移動0、急旋回なし、左右それぞれ約1.39ラジアンの腕振りと左右交互の動きを確認した。レベル11で矢印キーを使って穴を近づけ、2体とも転倒せず回避へ移り、左右の腕が約−3.20ラジアンへ上がることを確認。実行時エラー0。通常進行の通し確認とは区別する。
- 実行時エラー0。ビルド（型チェック・オフライン出力を含む）、Lint、確認画面の個別型チェックが成功。
- 今回の変更後の全12段階の通しプレイ、WebKit・iPhone実機は未実施。通常進行でのクリアは前回のモデル更新時の記録を参照する。
