# おもちゃのヒーロー・怪獣モデル

更新日: 2026-11-14

同日追記: オーナーの試遊を受け、[転倒判定の修正・静止して両腕で叩く対戦・両腕を上げた逃走](toy-battle-stability.md)へ更新した。最新の653項目の検証では、時間超過1件を単独で再実行して成功した。以下の637件成功・5件時間超過はモデルを更新した時点の記録。

オーナーの依頼に基づき、ヒーローをウルトラマン風の銀・赤の人型、怪獣をゴジラ風の恐竜型へ更新した。どちらも既存の玩具と合わせた、直方体だけの角ばったオリジナル造形とする。今回はこの2体が対象。

## デザインとゲームへの接続

- ヒーロー: 頭の稜線、段の付いた黄色い目、胸の青い部品と赤い模様、手袋・ブーツ。43個の直方体。
- 怪獣: 突き出した顎、小さな琥珀色の目、太い胴体・脚、爪、3列の背びれと段状の尾。71個の直方体。
- 配色は既存のおもちゃと合わせて彩度を抑え、粗さ0.75の材質を使う。画像テクスチャ・外部モデル・新しいライブラリは追加しない。
- 怪獣の横幅と奥行きの拡大はオーナーが承認。ヒーローの登録寸法48×180×42は維持し、怪獣は56×220×48から80×220×88へ変更した。高さ・配置・成長条件・得点は維持する。登録寸法は幅×高さ×奥行き。
- 最初の怪獣の試作寸法96×220×144ではレベル11の穴に収まらなかったため、尾のある輪郭を保ちながら最終寸法へ調整した。レベル11の穴の半径は48。
- 腕の肩関節は既存の `attack-arm` / `other-arm` に接続し、従来の対戦・回避・相手不在時の行動を引き継ぐ。
- 見た目の直方体から既存の当たり判定を生成する。脚の間・尾の周囲を外接箱で埋めない。ヒーロー・怪獣の逃走開始判定も実形状の水平半径を使い、長い尾を囲む箱の空の四隅によって逃走がレベル12まで遅れないようにする。他の種類の逃走判定は変更しない。
- 落下時は既存の処理で攻撃腕を通常姿勢へ戻し、剛体と表示の形状をそろえる。

今回の接続は、インストール済みのBlender公式MCPアドオンのTCP接続口（このセッションでは9191番）へ、そのアドオンのNULL文字区切りJSON形式でPython実行要求を直接送った。HTTPのMCPサーバーは経由していない。Codex・Blenderの接続設定ファイルは変更していない。

モデルを更新するときは制作スクリプトを修正し、Blender MCPのPython実行機能から実行する。専用のデザインシーンを再生成するため、そのシーンを手で編集した内容は再実行前に別ファイルへ保存する。元からあった別シーンは残す。BlenderのZ-upとゲームのY-up、および正面方向の違いは書き出しで変換する。

```python
from pathlib import Path
import bpy
file = str(Path(bpy.data.filepath).resolve().parents[2] / 'assets/blender/create_toy_characters.py')
namespace = {'__file__': file}
exec(compile(Path(file).read_text(), file, 'exec'), namespace)
result = namespace['result']
```

書き出したJSONには `npx prettier --write src/game/models/toy-characters.json` を適用する。
