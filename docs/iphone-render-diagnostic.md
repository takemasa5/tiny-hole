# iPhoneの点滅：実機での切り分け

2026-11-07 / 点滅は未解消。オーナーは箱の面ごとの透過へ変更した後も点滅を確認した。これまでのPCでの再現・改善だけでは、iPhoneの症状を解消できていない。

その後、指定された画面収録動画を直接確認し、[床が物体を上書きし得る描画順を修正](iphone-video-ground-order.md)した。以下のA〜E比較はその修正前の記録。修正後も診断スイッチは維持するが、iPhoneで解消したかは未確認。

## オーナーの実機結果（追加）

A〜Eのいずれもあまり変わらず、レベル1で激しく点滅し、レベル2で収まり、レベル3で再び微振動するという報告を受けた。透過を止めるBでも改善が乏しいため、透過単独を主因とする見立ては見直す。端末固有の描画・画面サイズの変化・物理やカメラの状態を含め、原因はまだ確定していない。

画面収録動画はチャットの添付上限を超えるため、iPhoneからMacへAirDropし、ユーザーが指定したファイル名・保存先から直接読み込む。原本は圧縮せず、プロジェクトのGit管理対象へコピーしない。レベル1・2・3で、画面全体の明暗、壁・物の位置、画面の拡縮をフレーム単位で比較してから次の修正を決める。

## 今回の範囲

通常ゲームの描画設定をさらに変更する代わりに、開発サーバー専用の比較画面 `checks/iphone-render.html` を用意した。実際の `startGame` を使い、おもちゃの同じ配置（シード42）から、描画条件を切り替えて開始する。ゲーム内部のレベル・座標・回収状態を直接書き換えない。音は比較中のみOFF。

左上のメニューを開き、Aの通常表示で症状を確認した後、まずBの透過なしで同じように移動する。Bで壁が不透明になるのは診断のための動作。成長してレベル2になったら、同じボタンを押すと同じ配置のレベル1からやり直せる。選択後はメニューを閉じ、壁が見える範囲を確保する。

| 項目             | 変更する描画条件                                                                   |
| ---------------- | ---------------------------------------------------------------------------------- |
| A 通常           | これまでの通常の描画設定                                                           |
| B 透過なし       | 遮蔽物の透過判定と材質切り替えを完全に止める                                       |
| C 奥行き精度     | カメラのnearを穴半径×0.015から×0.4へ変更。遠方やカメラの距離は維持                 |
| D 輪郭処理なし   | MSAAを使わず開始。この場合、既存の透過も通常のブレンド方式へ自動的に戻る           |
| E 床の重なりなし | 箱・部屋などの床面・模様を非表示にし、元の無地の地面だけを描く。床の物理形状は維持 |

DではMSAAと透過の方式が連動するため、Dの結果だけでどちらが原因かは断定しない。まずBで、透過処理を止めても点滅するかを分ける。A自体で再現しない場合も重要な結果として扱う。

各比較では古いゲーム・物理世界を終了し、キャンバスも新しく作る。WebGLコンテキストのantialias属性は同じキャンバスの再利用では変更できないため。終了した比較のコンテキストは解放する。診断画面の操作で通常ページの設定やブラウザの保存設定は変更しない。結果を自動送信する仕組みは追加していない。

## 実装上の境界

`startGame` の追加引数は開発モードでだけ受け付ける。通常ページはこの引数を渡さないため、透過・カメラのnear・MSAA・床の描画設定は従来どおり。配布ビルドでは診断指定を無視し、比較HTMLも通常の配布物へ含めない。設定ファイル・依存関係・配信設定は変更していない。

観測用スナップショットの `renderDiagnostics` に選択中のモードと実際のnear/farを追加した。既存の `occlusionRendering` でMSAAのサンプル数と透過方式も読める。通常UIへは追加表示しない。

## 確認済みと未確認

既存の316テスト・24ファイル、ビルド、Lintが成功。診断用TypeScriptも設定ファイルを変えず個別に型チェックした。

PC Chromiumの390×844・DPR2でA→B→C→D→E→Aを確認。シード42・おもちゃ・レベル1から開始し、nearは通常0.0012 / Cで0.032、MSAAは通常4サンプル / Dで0になっていた。メニューの表示範囲、選択後の折りたたみ、タッチ移動と指を離したときの停止、通常ページが通常モードで開始することも確認した。実行時エラーは0。
