## 世界と進行

同じ平面・同じ座標に、壁画を墓、墓を神殿、神殿を街が含む。成長して視野が広がると、先ほど遊んだ場所が小さく見える。

| レベル | 場所           | 対象と配置                                                                                           | 出口                             |
| ------ | -------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------- |
| 1〜3   | 壁画の物語     | 印章・スカラベ、薄い立体の人物・鳥・船。床へ太陽・鳥・帯状の物語を描き、人物たちはその上を行進する   | レベル4で壁画の東側の枠が開く    |
| 4〜6   | 王家の墓       | 壺、供物、宝箱、供物台、王棺、守護神像。中央にはこの段階では巨大に見える列柱と、巡回する神官を置く   | レベル7で墓の扉が開く            |
| 7〜8   | 神殿           | 彩色の柱、オベリスク、門、小神殿、スフィンクス像                                                     | レベル9で神殿の門が開く          |
| 9〜12  | 街とピラミッド | 露店、日干し煉瓦の家、ヤシ、街の門、列柱神殿、小ピラミッド。神官・ラクダに加え、巨大な神々が巡回する | 最終目標を実際に飲み込むとクリア |

- 穴の半径・カメラ・12段階の成長表は維持する。
- 閉じた枠・壁・扉には同じ位置の当たり判定があり、接近時は画面上の16pxの案内で開放レベルを表示する。案内が穴へ追随して境界そのものが移動する処理は使わない。
- 最終目標は幅・高さ・奥行きが各180の巨大ピラミッド。神殿の東壁から外縁まで10離した `(170, -100)` へ配置し、神殿にいる段階から大きな面を見上げられる比較対象にする。東側の出口と通路には重ねない。レベル制限で回収を止めず、傾いて落ちきればその時点でクリアする。
- 26種類の形状を用意する。レベル1〜11の在庫は各24個。これに補充箱11個、王棺1個、墓の列柱4個、神官16人、ラクダ12頭、街区の建物・設備200個、最終目標1個、巨大な神3体を配置する。行進する壁画の8個は各レベルの在庫に含む。
- 街は25区画に各8個の追加物を分散する。道路と歩行経路を空け、神殿前の成長用在庫だけに物量が偏らないようにする。
- 個数・寸法・進行レベル・移動速度は試作の仮値。地獄のように移動物の捕獲を必須にする変更はエジプトには加えない。

## 描画と落下

- 床の壁画・石畳は床のテクスチャに描く。同じ高さへ装飾板を何枚も重ねず、床を物より先に描く既存の修正を引き継ぐ。
- 固定壁を穴へ追随させず、動く物・穴・カメラには既存の物理更新間の描画補間を使う。
- 遮蔽する面だけを対象にする既存の透過処理を共用する。飲み込める小物を一律に透過する変更は加えない。
- 当たり判定は表示モデルの部品ごとに作る。門・机・列柱神殿の下、人物や鳥の脚の間を、見えない大きな箱で塞がない。
- 薄い人物の押し出し形状は、隣接部品を合体しても体積が増えない場合だけまとめる。くぼみ・隙間を残しながら物理部品数を減らす。物が穴に掛かる場合は支持の失われ方に従って傾き、落下中は行動制御を解除する。
- 遠い街の見た目と近傍の物理演算を分離する。小さくなった旧段階の物を退役させ、落下・接触中の物は維持する既存方針を引き継ぐ。終盤には微小な行列も退役する。

## 街の巨大な神々（2026-11-08）

オーナーが初版をiPhoneで確認し、ちらつきがなく問題ないと評価。その後の「目標を神殿近くへ」「街で巨大な神々を追いたい」という要望を反映した。

| 神       | 寸法（幅・高さ・奥行き） | 主な特徴                   | 飲み込める目安 |
| -------- | ------------------------ | -------------------------- | -------------- |
| アヌビス | 48・180・3               | 黒い頭と長い耳、金の装飾   | レベル11       |
| ホルス   | 56・220・3.6             | 青い頭飾りと金色のくちばし | レベル11       |
| セベク   | 80・260・4.2             | 緑の頭と長い口             | レベル11       |

壁画の人物と同じ薄い横顔の板を土台に、アヌビス・ホルス・セベクの頭と色を組み合わせる。厚さは高さの2%未満。絵柄が横を向いて見えなくならないよう、板の向きは一定にし、脚は板の面内で動く。

普段は街の四角い巡回路を歩く。水平外形が穴に入る大きさで、距離が穴半径の4倍未満になると逃げる。逃走中は半径の6倍まで警戒を維持する。速度は、穴の最高速 `半径×7` を基準に、4秒周期の最初の2.6秒を1.05倍、残り1.4秒を0.78倍とする。速い区間を直進で追うだけでは追いつけず、速度が落ちる区間や先回りで捕まえる構成。逃走だけを速くし、通常の巡回速度は倍率0.45を維持する。

逃走時に巡回路の矩形から外れた途端に初期位置へ引き戻していた処理は、神々には使わない。街の外周では街の中に収まる方向へ向きを変え、速度を維持する。

歩行・逃走中は全回転軸を固定する。足が支持されたまま外形に穴が接触した場合は倒れず、穴と重なり、実際の最下面が地面より一定量沈んだ時点で全軸を解放して物理落下に移る。神々以外の物の姿勢解放条件は維持する。実際に落ちきった場合は目安レベル未満でも回収する。

巡回路にはそれぞれの水平外形の半径と余白4を確保し、静止物を配置しない。街の200個の追加物は維持する。既存の小さな神官・ラクダも残す。巨大な神々は遠方の姿を早期から表示し、物理演算は既存の近傍有効化を使う。

追加後のiPhone実機・WebKitは未確認。初版のiPhoneでの評価と、今回の追加後のPC検証を分けて扱う。
