## 遊び方

左上で「アメリカ」を選ぶ。飲食店で小物を集め、商店街の売店・車、外側の住宅街の家、自由の女神を狙う。地面にエリア名は書かず、地区の配置傾向と色分け、HUDの現在地と案内を使う。

清掃車は物を押して場外へ運ぶ。先に物を回収するか、別の場所へ向かうか、成長して清掃車を飲み込むかを選べる。押し出された物では成長しない。供給地点の緑の矢印を目印に、トラックの紙箱や搬出口の物を回収できる。場外になった個数と補充数は画面下へ表示する。

制限時間・失敗・体力・成長量の減少はない。操作、穴の画面上の大きさ、8段階の半径とアメリカの成長閾値は第1試作を維持する。

## マップと初期配置の仮値

- アメリカは約69×69から100×100へ拡張。最大段階の穴の中心が動ける幅は約58.4から89.8へ広がる。
- 序盤の食べ物と商店街の物は従来の範囲に集中させ、小物を全域へ薄く散らさない。家は右側の拡張領域にも配置する。自由の女神はX=35〜43、Z=-30〜30へ配置する。
- 地区境界はX=2、16。境界に壁や解放条件はない。
- 初期の動的オブジェクトは452個。第1試作の工事ロボット2体を清掃車1体へ置換し、ほかの種類・個数・積み上げ数を維持する。固定供給設備2か所は、この個数と成長対象に含めない。
- 清掃車は(8,9)、最初に押す車は(8,14)に配置する。そのほかはシード付きランダム配置。供給設備と搬出場所の領域も確保して初期重なりを避ける。
- 移動境界、歩く人の境界、地面の模様とUVをステージごとの広さへ合わせる。アメリカの床外周半径を120から180へ広げ、穴が隅へ移動しても反対の隅の物を支える。

## 清掃車の仮値

- 1体、寸法3.2×1.8×2.8、80点。箱型の動的剛体と密度3を使う。
- 速度3.2。最初の車の後ろへ回り、剛体接触で押す。物の座標や速度を直接書き換えて運ばない。
- 押す対象は地表上の食べ物・紙箱・タイヤ・売店・車。人・家・目標物・落下中の物は選ばない。
- 次の対象は15以内から選び、外周までの距離と固定供給設備を避ける向きで押す。1つの対象に24秒かかったら別の対象を探す。障害物を避ける本格的な経路探索は導入しない。
- 場外へ押した後は内側へ戻り、巡回と次の回収を続ける。清掃車自身は場外撤去しないため、戻ったところを狙える。
- 自由の女神と清掃車の直接接触は衝突フィルターで除く。ほかの接触などで目標が境界外へ動いた場合は、内側へ直立させて戻す。
- レベル5以降は穴に収められる。支持を失うと水平制御を止め、回転と落下を物理演算へ任せる。通常の回収判定で一度だけ加点し、以後の押し出しは止まる。

## 場外と飲み込みの区別

物全体が場外へ出たとき、具体的には中心のXまたはZの絶対値が「50＋種類の水平半径」を超えたとき、加点せず撤去する。

穴の近くで物全体が地表より下へ入ったことを記録し、その後に回収面を通った物だけを飲み込みとして加点する。穴が移動してから回収面へ達しても記録を保持する。場外の撤去を飲み込みやクリアのイベントへ渡さない。回収・場外撤去とも剛体と描画資源を解放する。

## 供給地点の仮値

供給設備は固定した見た目と衝突形状を持ち、清掃車の対象・成長対象に含めない。穴が下を通っても設備は残る。

| 設備           | 位置    | 基本供給             | 通常間隔 |
| -------------- | ------- | -------------------- | -------- |
| フードトラック | (-12,9) | 紙箱1点              | 8秒      |
| 商店街の搬出口 | (8,-20) | 現在の段階に合った物 | 12秒     |

搬出口はレベル1〜2でタイヤ3点、3で売店22点、4〜5で車32点、6〜8で家178点を供給する。搬出位置はトラックの横(-7,9)、搬出口の前(8,-13)を起点に、空いている周辺を探す。

- 現在の穴に収まり、場内にあり、落下中ではない物のポイントと現在の累積値を足す。次の成長閾値へ届かなければ、2秒間隔で搬出口からの追加供給を試みる。
- 1地点から生成した物は同時に8個まで、動的オブジェクト全体は480個まで。上限時もほかの地点の供給を止めない。
- 成長に使えない生成物が地点の枠を埋めて供給を妨げている場合は、その生成物を加点せず再利用し、現在の段階向けの物へ置き換える。
- 既存の物・設備・穴との重なりを避ける。穴の中へ直接出さず、地表の少し上から通常の重力で置く。空き場所がなければ後で再試行する。
- 生成物には実行中に重複しないIDを付け、回収の二重加算を防ぐ。
- 非表示中とクリア後は供給と清掃車の更新を止める。再開・ステージ切り替えで供給数、場外数、敵の状態を作り直す。
