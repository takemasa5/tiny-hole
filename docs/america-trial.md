## 遊び方

左上で「アメリカ」を選ぶ。飲食店で食べ物・紙箱を集め、右の商店街で売店・車、その右の住宅街で家・自由の女神を狙う。画面下に成長段階に応じた案内、左上に現在の地区を表示する。

オーナーの試遊評価により、地面へエリア名を描く表示は削除した。地区ごとの配置傾向と地面の色分けを維持する。

表示修正後は全53テスト・型チェック・ビルド・Lint・フォーマット確認が成功。Chromiumで地面テクスチャへの文字描画が0件、地区の3色と現在地表示が維持されること、実行時エラー0件を確認した。[表示修正の確認結果](../reports/america-ground-label-removal-2026-10-30/1793325803337/results.json)。今回のiPhone実機・WebKit確認は未実施。

工事ロボットは商店街を巡回する。黄色い円は土の着地点で、予告された時点から変わらない。穴の中心が円の外へ出ると回避できる。命中すると穴の縁が茶色になり、1.2秒だけ移動が遅くなる。成長後はロボット自体を通常の物理落下で飲み込める。

制限時間・失敗・体力・成長量の減少はない。ドラッグ・タッチ・WASD・矢印キーを維持する。敵を飲み込まずに成長・クリアするための物量も確保する。

## 試作用の仮値

マップ面積と穴半径は維持する。物の配置は地区内でシード付きランダムに生成し、道路・境界・初期の穴・ほかの物との重なりを避ける。アメリカの物は従来の道路から一定距離の帯に限定せず、地区内の道路以外の場所へ配置する。

| 地区         | X座標の範囲 | 主な物                           |
| ------------ | ----------- | -------------------------------- |
| 飲食店       | 左端〜2     | ハンバーガー・ホットドッグ・紙箱 |
| 商店街       | 2〜16       | 売店・タイヤ・車・工事ロボット   |
| 住宅街・広場 | 16〜右端    | 家・自由の女神                   |

人24人は従来どおり歩行・逃走する。地区の境界に壁や解放条件はない。工事ロボットも地表上を物理的に移動し、通行人や物へ接触する。障害物を避ける経路探索は導入しない。

| 1      | 0.9    | 0                  | 0               |
| 2      | 1.15   | 8                  | 8               |

家を12→16軒、車18台、工事ロボット2体を追加する。その他の種類・積み上げ数は維持し、合計は429→453個。車は寸法2.6×1.1×1.35、32点。工事ロボットは3.2×2.2×3.2、80点。いずれも単純な箱の衝突形状を使い、目安として車はレベル4、ロボットはレベル5で水平投影全体を穴に収められる。実際の落下は姿勢と支持に左右される。

| 敵の挙動       | 仮値                                                |
| -------------- | --------------------------------------------------- |
| 巡回           | 初期位置の周辺、半径1.5、最大速度0.65               |
| 攻撃開始       | 敵と穴の中心の距離が「穴半径＋7」未満               |
| 予告           | 0.9秒、着地点固定                                   |
| 土の飛行       | 0.45秒                                              |
| 命中判定       | 着地点と穴の中心の距離1.6以内                       |
| 攻撃後の待ち   | 4秒                                                 |
| 減速           | 1.2秒、移動速度とドラッグ移動量を55%へ              |
| 連続命中の保護 | 命中から4秒は追加命中を無効化、効果時間を延長しない |

予告円・土は描画用で、剛体や成長対象を増やさない。敵は落下開始時に巡回と攻撃を止め、投擲途中なら取り消す。落下後は通常の回収・加点・資源解放を使う。非表示中とクリア後は物理更新と攻撃の時間を進めない。再開・ステージ切り替え時に敵と減速状態を作り直す。既存のアメリカ人の発砲は演出のみを維持する。

## 実装の入口

- `src/game/stage.ts`: 地区・種類・個数・成長表・生成。
- `src/game/construction-enemy.ts`: 巡回・予告・投擲・命中・減速。
- `src/game/america-visuals.ts`: 車・ロボット・投擲の見た目。
- `src/game/runtime.ts`: 操作・物理・敵・回収の接続。

## 検証と評価

`npm test` で地区内の生成、敵を除いた成長量、閾値の境界、着地点固定、回避、落下による攻撃中断、連続命中の保護、回復、車・ロボットの物理落下と一度だけの加点を調べる。

`npm run dev` の起動後、`node checks/america-trial.mjs` でChromiumの通常ドラッグによる開始からクリア、予告・命中・減速・回復・回避、敵の飲み込み、次ステージへの自動移行、スマートフォン幅のタッチ操作と表示を確認する。結果は実行ごとの `reports/america-trial-2026-10-30/` 配下へ保存し、過去の結果を上書きしない。

プレイ時間1.5〜2倍は目標で、ポイント閾値の倍率から達成を判断しない。ブラウザの自動操作時間も、人が遊んだときの長さや面白さを示す測定値としては扱わない。待たされる感覚、次に狙う物の分かりやすさ、敵の煩わしさはオーナーの試遊で評価する。
