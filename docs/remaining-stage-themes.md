各ステージは5つの平面上の空間を壁・扉・ゲートでつなぎ、レベル4・7・9・11で次の出口を開く。既存の12段階の穴の寸法は変更しない。最終目標は最後の出口の正面に置き、近づく前からプレビューを残す。終盤は32街区へ対象を配置し、道路の余白を確保する。

床・道路・水面は物体より先に描く背景へ統合する。表示モデルの実部品から当たり判定を作り、輪や脚の間を不可視の箱で塞がない。人物の逃走は飲み込める寸法になってから発動し、落下後は移動制御を解除する。目標も実際に飲み込めば対象レベル未満でクリアする。

## 再検証

通常の開発サーバーを起動し、別のターミナルから対象ステージを指定する。`HOLE_STAGE` は `america`・`harbor`・`office`、`HOLE_URL` は確認するサーバーのURL。

```sh
HOLE_STAGE=office HOLE_SEED=42 HOLE_URL=http://127.0.0.1:5173/ node checks/district-flow.mjs
HOLE_STAGE=office HOLE_URL=http://127.0.0.1:5173/ node checks/district-mobile.mjs
```

検証用操作は読み取り専用の状態取得と通常のキー・タッチ操作を使う。レベル・座標の書き換えや強制回収は行わない。倒れかけの同じ対象を追い続けないように時間の上限を設ける。

反映先では検証済みのソース・テスト102ファイルの一致と、3ステージのタッチ・出口・リスタート・切替を再確認した。[反映先の確認記録](../reports/stage-themes-2026-11-13/root-review.json)。
